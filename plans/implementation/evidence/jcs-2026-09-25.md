# RFC 8785 intent canonicalization — 2026-09-25

K01/TK-06 partial evidence. The Core now depends on pinned
`rfc8785==0.1.4` for canonical JSON. It is a pure-Python, no-dependency
Apache-2.0 package; the implementation remains external rather than copied
into the Core or imported from the Nexus application. Core retains its own
pre-validation for JSON types, safe Python integers, finite floats and Unicode
surrogates. The strict parser rejects duplicate keys and non-finite tokens,
including exponent overflow. The bundle generator emits three independent
canonical strings and SHA-256 vectors; tests also cover RFC 8785 Appendix B
IEEE-754 examples including negative zero, subnormal, exponent thresholds and
round-to-even.
