## Decisões de máquina de estados (C8-00.03)

**Lease** (transição única `_classify_lease_row` + `_apply_lease_classification`,
compartilhada por caminho direto/callback tardio/reconciliador):
`COMMITTED_REVOKE` (row revoked → restringe) · `COMMITTED_RENEW` (row ==
proposta → aplica se binding compatível) · `NOT_DELIVERED` (row == base
exata + produtor terminado → resolve a tentativa) · `SUPERSEDED` (row
válida ≠ proposta ≠ base → resolve a tentativa, cerca o binding) ·
`UNKNOWN` (sem prova → hold + reconciliador com backoff; contenção livre).

**Recurso tardio** (um registro por recurso: `_LateHandleRecord` com
unidades físicas; `_ReleaseObligation` para a obrigação durável):
OPENING (producer+guard) → HANDLE_OWNED (registro antes do primeiro
await) → CLOSING/FORCE_IN_FLIGHT (unidades do registro, força paralela)
→ OWNED_UNKNOWN (handle forte retido; retry no próximo lifecycle) →
STOPPED_RELEASE_PENDING (obrigação durável retryable) → RELEASE_CONFIRMED
(pops + disposal elegível).
