# PC07 — Liberação de sessões encerradas (C1)

## Change (runtime.py)

- **Registry vivo + túmulos bornados.** `_sessions` continua sendo o
  registro vivo; novas `_SessionTombstones` (capacidade 1024, FIFO)
  registram apenas o desfecho honesto de ownership observado na evicção
  (`released` ou `unknown`) — nunca o adapter nativo nem closures de
  tasks.
- **Evicção segura (`_schedule_eviction`, F06).** Disparada somente
  quando o encerramento foi **observado** (`binding.closed` após stop
  comprovado). Uma tarefa dedicada aguarda (bornado, 5 s) o pump, o
  watcher de lease, o sink e a task de força; então remove o binding sob
  o lock de estado com verificação de identidade — nenhum callback tardio
  reinstala entradas. Sessões `unknown`/incertas **nunca** são evictadas
  (slots e ownership preservados).
- **Histórico preservado.** `inspect` de sessão evictada lê o túmulo:
  `released`/`CLOSED` para histórico liberado, `unknown` caso contrário —
  `process_state` permanece `UNKNOWN` (nada é inventado). `shutdown`
  responde `already_closed` para sessões evictadas a partir do túmulo.
  Receipts/claims/eventos continuam no journal; reenvio do mesmo ID
  retorna o recibo conhecido sem re-execução.
