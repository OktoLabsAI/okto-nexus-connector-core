# K03 selected Pi version observation — 2026-09-25

`discovery.probe_selected_pi` now reuses the Core-owned bounded native version
observer for a locally selected `pi_rpc` candidate. It validates absolute
working directory, selected adapter identity, binary SHA-256 and architecture
before execution; filters environment keys; passes only the absolute binary
path plus `--version`; and checks the binary fingerprint again afterwards.
The observer owns and bounds the process tree and accepts only a narrow version
format. The returned candidate has an observed version, not a capability grant.

The full local suites passed on Windows/Python 3.13 (361 passed, 68 skipped)
and WSL2/Python 3.12 (416 passed, 13 skipped), each with the expected legacy
Pi fault-injection thread warning. Focused probe regression tests cover the
sealed environment, cross-adapter rejection and binary drift. They stub the
version observer; no installed Pi executable or real-provider qualification
was available. Effective native qualification sets remain empty.
